# etc

룰 본문(`rules/`)과 분리된 **메타·출처 및 환경 설정** 디렉터리.

| 파일/폴더 | 용도 |
|------|------|
| `sources/` | 룰별 참고 문헌, URL, 내부 스킬·룰 통합 출처 |
| `ghostty/` | Ghostty 터미널 에뮬레이터 설정 및 테마 |
| `mac-setup.md` | 작업 PC 필수 소프트웨어 구성 요소 및 초기 설정 가이드 (SSOT) |
| `bh-onboarding.md` | 로컬 복습용 온보딩 가이드 문서 |

`rules/`를 수정할 때 관련 `etc/sources/<rule-name>.md`도 함께 갱신한다.
