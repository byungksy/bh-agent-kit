# Prompt Anchor (`->` 및 지시어)

## When

사용자 메시지에 `->`, `이거`, `그거`, `위 내용`, `직전 답` 등 **직전 맥락을 가리키는 지시**가 있을 때.

해당 없음: `@파일`·경로·심볼이 명시되어 코드 탐색이 요청된 경우.

## Contract

- **MUST** 같은 스레드의 **직전 assistant 메시지**를 먼저 해석한다.
- **MUST NOT** 기본 동작으로 transcript grep·repo 전수 탐색을 시작한다.
- **MAY** Read/Grep/transcript는 다음일 때만:
  - 직전 턴에 답이 없거나 compaction으로 불명확할 때
  - 사용자가 `@파일`, 경로, 심볼을 명시했을 때
  - 구현에 필요한 사실이 대화·지정 파일 어디에도 없을 때
- 애매하면 **00-inquiry-first**: 역질문 **1문장** 후 진행 (탐색으로 대체 금지).

## Anti

- `->`만 보고 agent-transcripts JSONL부터 뒤지기
- 직전 턴에 이미 있는 표·결론·코드 인용을 재탐색하기

## 사용자 권장 (에이전트가 필요 시 안내)

- 새 세션·긴 스레드: 티켓·브랜치·`@파일`·앵커 1줄 인용
- `->`는 직전 턴 가리키기용; 몇 턴 전이면 섹션명·한 줄 인용 병행
